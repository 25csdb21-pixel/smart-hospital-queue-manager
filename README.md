# 🏥 Smart Hospital Queue Manager

A simple and user-friendly web application designed to manage patient queues in a hospital efficiently.

## 📌 About the Project

The **Smart Hospital Queue Manager** helps hospital staff register patients, generate tokens, manage waiting queues, and handle emergency patients with priority.

This project is developed as a **mini project using HTML, CSS, and JavaScript**.

## ✨ Features

* 👤 Patient Registration
* 🎫 Automatic Token Generation
* 👨‍⚕️ Doctor Selection
* 🚨 Emergency Patient Priority
* 📋 Patient Queue Management
* ▶️ Call Next Patient
* ✅ Patient Status Tracking
* 📊 Total, Waiting and Completed Patient Count
* 💾 LocalStorage Data Storage
* 📱 Responsive Design

## 🛠️ Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and responsive design
* **JavaScript** – Application logic and queue management
* **LocalStorage** – Storing patient data in the browser

## ⚙️ How It Works

1. Enter the patient's name and age.
2. Select the required doctor.
3. Select the patient priority.
4. Click **Generate Token**.
5. The patient will be added to the queue.
6. Click **Call Next Patient** to call the next patient.
7. Emergency patients are given priority.
8. The dashboard displays patient statistics.

## 🔄 System Flow

```text
Patient Registration
        ↓
Token Generation
        ↓
Patient Queue
        ↓
Check Priority
        ↓
Call Next Patient
        ↓
Doctor Consultation
        ↓
Completed
```

## 🎯 Objective

The main objective of this project is to reduce manual queue management and provide a simple digital system for organizing patients in a hospital.
